Interactive Fractal Generator 🔯
A small project where you can play around with fractals and control how they look!

I made this project while learning web development. It's one of my first bigger projects, and honestly, I learned a lot while building it. I also took some help from web resources and YouTube tutorials whenever I got stuck.

__Features:- 

Reload for new colors: Refresh the page to get a different color combination.
Spread Slider: Adjust the spread of the fractal and see how it changes.
Randomize Button: Generate a random fractal with a single click.

💭 About the Project
I'm still a beginner in web development, and this is one of the first times I've tried building something a bit bigger on my own.

It wasn't always easy, but I enjoyed experimenting with the fractals, trying different settings, and figuring things out along the way.
